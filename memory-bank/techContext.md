Regenerate models with Blender using scripts/build_assets.py and --python-exit-code 1. assets/source/.gdignore prevents Godot from trying to import the editable .blend source; the runtime uses the exported GLBs and committed .import settings. Regenerate the original short sounds with python3 scripts/build_audio.py.

Route and timing runs go through `scripts/route.sh`, which runs one headless process per level in parallel with `--fixed-fps 60` and the driver's `--simulation-clock`; the driver also sets `OS.low_processor_usage_mode_sleep_usec = 0`, because headless Godot otherwise sleeps about 6.9 ms per frame and caps the game at about 144 fps, which made a "simulated" route run at real-time speed. The driver refuses `--simulation-clock` when the process was not started with `--fixed-fps`, and each ROUTE_RESULT carries `simulated_per_wall_second`, so a slow harness shows in every report. `route.sh` holds the only copy of the level gates (won, 360 to 600 s, no missed meals, no stalls over 2 s, longest meal gap at most 4 s), prints PASS or FAIL per level, and exits 1 when any level fails; a miss is a failure to fix, not noise. A route now runs about 2.3 times faster than real time per level; visible windows are fine (owner, 2026-09-22), but keep them muted and do not rerun the same route without a reason, because repeated identical runs were what annoyed the owner.
The level music is written in LilyPond (/opt/homebrew/bin/lilypond, 2.26.0) as assets/source/music/{sugar_water,tide_pool,skatepark_bowl,cosmic_web}.ly and rendered through the MuseScore 4 CLI (`/Applications/MuseScore 4.app/Contents/MacOS/mscore`, 4.7.5) with Muse Sounds, which needs Muse Hub 3.1.1 or later on macOS. `uv run scripts/build_music.py` engraves each score and imports its MIDI without the bass into an .mscz that keeps the MuseSounds profile. It retargets parts that import as templates Muse Sounds does not play (RETARGET), pins explicit Muse sounds where the default is wrong (OVERRIDES), and asserts through `--tracks-diff` that every part maps to `muse_sampler_sound_pack`. It then renders without `--sound-profile`, which would discard the pins, and checks the run's log for "MuseSampler successfully inited". The upright bass track is played by scripts/sfz_player.py from the Larry Seyer SFZ unpacked under ignored .tooling/upright-bass/. The bass follows MuseScore's clock, which the build measures by rendering a side-stick click at every bass note. The build masters to -16 LUFS, writes the game's Oggs under their existing names in assets/audio (particle_shuffle, tidepool_bossa, skatepark_samba, cosmic_drift), sets each Ogg's Godot `loop_offset` to the score's first rehearsal mark, and leaves an uncompressed builds/music/final-<score>.wav. Pass slugs to build a subset; `--sounds ms-basic` renders General MIDI previews into builds/music/preview. Engraved pages, spectrograms and per-piece reports, including each part's Muse sound, land in builds/music.
