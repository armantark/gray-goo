# Project brief

Build a modern Tasty Planet-style top-down eating game with 3D assets and a gray goo protagonist. The proof of concept has four consecutive opening levels across two neighboring scale bands, with two distinct environments per band. The long-term target is 60 levels. Begin at subatomic scale. Objects must use proper relative scales; the exact starting size and scientific representation remain open. The provisional environmental progression follows a coherent outward journey through a laboratory sample, with recognizable larger surroundings appearing as their sizes become relevant.

Generate art direction concepts with Codex imagegen and iterate against actual in-game screenshots while meeting a measured 60 fps target at 1920 × 1080. The selected art direction is smooth cartoon geometry throughout, with cel shading and outlines. Gameplay should resemble the original Tasty Planet. Everything is a reference for scale and theme diversity within the same scale band, not for gameplay. Background story is outside the present discussion; the lab question concerns level-theme progression. Engine and performance measurement criteria remain undecided. Use the local M1 Max Mac Studio as the proposed benchmark device unless the user specifies another target.

The user prefers Blender CLI over MCP and confirmed that Astra's reasoning setting is already correct. Use the existing Blender installation through its bundled executable. No game implementation starts before the requested design interview settles the material decisions.
