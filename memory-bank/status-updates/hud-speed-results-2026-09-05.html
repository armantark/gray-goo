What you see now

03 Frame rate in dense scenes

Cause

Every physics substep scanned all 2687 Sugar Water foods twice, once for obstacles and once for eating. Each slow tick made Godot run extra ticks to catch up, which made the next frame slower. The hand-off attributed this to body contact; profiling showed the contact loop was a minor share.

Fix

Foods wander a bounded distance from where the layout placed them. A grid keyed by placement, with a margin for wander and for the widest collider, answers both queries from a few cells. Astra's obstacle check now compares results as sets because order was never a contract.
