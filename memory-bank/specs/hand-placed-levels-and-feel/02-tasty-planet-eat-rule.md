# 02: Tasty Planet eat rule

**What to build:** The goo eats any object that looks smaller than itself, on the first contact of the goo surface with the object. Objects that look larger block it. The tier number controls only what is shown. Edible food never acts as a wall. One edibility function serves eating, blocking, and the arrow.
