## Goo simulation leaf contract

goo_body (Astra) owns src/goo_body.gd and shaders/goo.gdshader only. Implement a genuinely deformable, contact-coupled, rolling sticky mass. Body movement cannot be a rigid sphere with cosmetic wobble. Use the native-capability evidence from engine_research when available; a small particle-shell solver is permitted if native SoftBody3D cannot deliver the required driven contact/adhesion/growth interface. Keep the solver readable and bounded. No external libraries or installations.

Interface: class_name GooBody extends Node3D. Root calls configure(start: Vector3, starting_radius: float, ground_height: Callable, obstacles: Callable, field: Rect2) after adding it to the scene. ground_height.call(world_point: Vector3) -> float returns the surface height at that X/Z, including the skatepark bowl. obstacles.call(center: Vector3, reach: float) -> Array returns nearby unconsumable solids; each Dictionary has center:Vector3 (horizontal center), radius:float (horizontal collision radius), bottom:float, top:float, and optional body:RigidBody3D (can receive an impulse). All values are world coordinates. Treat solid obstacles as finite vertical cylinders for this interface. Field Rect2 maps world X/Z. The leaf handles floor, bounds, and obstacle contact in its simulation.

Public properties: radius:float (current visual/physical radius), velocity:Vector3 (body center velocity), tint:Color (mean retained food tint). Node global_position is the current body center. Public methods: set_drive(direction: Vector3, speed: float) for a normalized horizontal desired direction and world-units/sec speed; grow_to(new_radius:float) smoothly adjusts body size; absorb(at:Vector3, color:Color, fraction:float) adds localized pigment/contact deformation, fraction is consumed volume divided by current goo volume, clamped 0..1; celebrate() adds a stronger body response; touches(point:Vector3, object_radius:float)->bool tests the deformed body's contact envelope rather than remote suction. Goo is initially gray. Pigment starts local and diffuses through the organism while its mean color persists. A smooth mesh with sufficient render vertices must avoid a visible low-poly look. Use toon shading and a dark outline; root handles the occluded silhouette if the leaf exposes a render mesh or duplicates a pass.

Expose an occluded silhouette compatible with an opaque obstacle and subdued outline (no obstacle fading). If a render-priority/depth approach requires root camera/environment support, document the exact integration requirement. No GUI or screenshots: basic headless parser/runtime checks only, root owns the single final visual/performance pass. Do not create test suites or add fake success counters. No Git/config/push, external model/network calls, other tasks, secrets, packages, rules, children, or writes outside owned paths. Report papercuts to root. Keep implementation and evidence truthful; when blocked return exact evidence, never message another session.

CHECK: Godot headless import and a temporary script under /tmp using the public interface, once an engine is available. EXPECT: no parse/runtime errors; grounded body under gravity, bounded movement, growth and localized color calls run without invalid values. Do not add permanent tests. Report actual commands and any native capability tradeoff. Root independently rechecks integration and performs the final visual/performance pass.
